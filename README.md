# 轻记账（Android）

一款离线优先的个人记账本。当前版本为 **v0.7.1**。源码对应[项目计划书](项目计划书.md)。

## 功能

- 首页：顶部显示活动余额、本月支出、收入和结余；下方常驻记账表单、总预算和最近五笔账目。点击最近账目可编辑或删除；未保存的表单按账本保存在本机。
- 连续记账：保存成功后只清空金额和备注，保留类型、账户、分类和日期；保存失败时仍保留草稿。
- 日期：记账、明细筛选、统计、预算月份、定期到期日及定时转账日期均使用应用内日历选择。年份和月份有独立按钮；点选日期后确认，窄屏并排日期框使用紧凑格式显示。
- 选择列表：账户和分类下拉列表始终从选择框下方展开，默认最多同时展示四条；下方空间不足时自动缩短，可在列表内滚动。账户条目左侧为名称、右侧为当前余额。定期账户不出现在账户选择列表中，仍可在“账户”页查看与管理。
- 统计：按月份查看支出类目、收入类目、正余额账户的饼状图，以及每日总余额折线图；负余额账户单列显示。折线图可单独设置起止日期（最多 366 天），纵轴围绕实际余额变化自动缩放，横轴日期刻度随范围调整；点按折线可查看当天日期与金额。
- 主题：在设置页选择淡黄、淡粉、淡紫、淡蓝、淡青或淡绿；默认淡紫，切换颜色立即生效并保存在本机。桌面图标在离开应用后更新，避免部分启动器在切换图标时关闭前台应用。
- 图标：采用“清爽钱包”方案 B，桌面图标跟随所选主题色切换。
- 金额输入：首页记账、编辑账目、账户初始余额、定时转账及预算都使用应用内计算器。计算器从底部弹出，按键为 `C × ÷ 退格 / 7 8 9 − / 4 5 6 + / 1 2 3 % / 0 00 . =`，括号在算式区右上角；完整算式保留到填入金额，记账时自动追加到备注。普通金额输入最多两位小数，不会唤起系统文字键盘。
- 账户：预设不可修改的“未指定账户”和可编辑、删除的“微信”“支付宝”“现金”；账户页显示各账户余额和全部余额，“未指定账户”固定排在末尾，支持普通、活期、定期账户。
- 活期：设置年化利率（百分数，最多四位小数，例如 `0.8860`），按每日余额计息，月末生成利息收入；本金随时可转入或转出。
- 定期：设置到期日与年化利率；到期前不能转出，到期日按实际每日正余额生成一次利息收入，之后本金可取用，不自动续期。
- 定时转账：在账户页创建每天、每周或每月任务，可停用。每月 29–31 日在短月按月末执行。
- 分类：支出和收入各有不可更改的“未分类”，固定排在分类列表末尾；其他预设与自定义分类均可编辑、删除。删除后旧明细在默认项下显示。
- 账本：设置页可新建、命名和切换账本，各账本的账户、分类、预算和账目分开保存。
- 明细：按日期范围、账户、分类筛选；用三栏显示范围内的支出、收入与结余，并显示各账户、一级分类支出。
- 收支结余摘要：首页和明细页保持三栏，摘要数字不显示人民币符号，字号略微缩小；按实际可用宽度依次选择两位小数、一位小数或整数，特别长的整数继续缩小字号。摘要按四舍五入显示，原始金额和计算精度仍保留到分。
- 预算：每月总支出预算，以及除“未分类”外每个一级支出分类的月预算；首页与预算页均用颜色进度条提示。“未分类”的支出仍计入总预算。
- 同步：首次打开时选择本地文件夹。应用优先使用所选目录本身或其中已有的账本目录（含 `ledger-v1`），只有未找到时才创建 `LightAccountBook`。FolderSync 可通过 WebDAV 把实际使用的账本目录与坚果云双向同步；旧版已选目录继续使用原有布局。

## 首次使用

1. 首次打开，按提示选择本地文件夹。若选中的就是旧账本目录，或其下已有账本目录，应用会复用它；否则创建 `LightAccountBook`。账本数据位于所用目录的 `ledger-v1` 中；新增账本的数据放在 `ledger-v1/book-<账本 ID>` 中。如检测到多个已有账本目录，应用会提示你直接选择目标目录。
2. 可直接使用预设账户和分类；在“账户”页修改账户名称、初始余额及理财类型。已有用户升级后会继续沿用此前选择的目录布局。
3. 如需跨设备同步，按[坚果云的 FolderSync 教程](https://help.jianguoyun.com/?p=2887)建立“双向”任务，把每台设备上应用实际使用的账本文件夹设为本地同步文件夹。第二台设备应先完成文件传输，再开始记账。
4. FolderSync 完成文件传输后，打开应用或点“立即刷新”。同步是最终一致的，完成速度取决于 FolderSync。

不要选择存储根目录、整个 `Download` 目录或 `Android/data`；Android 的系统文件夹选择器会限制这些位置。更换同步文件夹会将本机记录写入新目录，并导入其中已有记录；操作前应确认选择正确。

## 构建

需要 JDK 17 和 Android SDK Platform 36，并接受相应 Android SDK 许可。在项目目录运行：

```powershell
.\gradlew.bat :app:assembleDebug
```

成功后 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。这是供个人测试的调试包；正式发布需自行配置签名。

如果项目路径含中文，Windows 下 Gradle 的单元测试运行器可能找不到测试类。可把项目暂时映射到英文盘符再运行测试；下面的路径请替换为自己电脑上的路径：

```powershell
subst P: 'C:\path\to\your\project'
$env:JAVA_HOME = 'C:\path\to\jdk-17'
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
$env:ANDROID_HOME = 'C:\path\to\android-sdk'
Set-Location P:\
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug --no-daemon '-Pkotlin.incremental=false'
```

本版测试与模拟器验证结果见[验证记录 v0.7.1](验证记录-v0.7.1.md)，前版完整界面和卸载恢复检查见[验证记录 v0.7.0](验证记录-v0.7.0.md)。

## 数据如何计算

- 金额以整数“分”存储；输入金额最多两位小数。
- 计算器按括号、百分号、乘除、加减的顺序求值，只在最终金额处四舍五入到分；`10%` 表示 `0.1`，例如 `200×10%=20`。有实际运算时，算式会写入备注；再次计算会更新备注末尾的旧算式，不覆盖手写文字。
- 单账户余额 = 初始余额 + 该账户收入 − 该账户支出 + 转入 − 转出。
- 全部余额 = 所有账户余额之和；活动余额只包含普通、活期和已到期定期账户。转账不改变全部余额，也不计入月收入或月支出；本月结余 = 本月收入 − 本月支出。
- 删除账户保留原始明细及其账户 ID，显示和汇总时把该账户余额并入“未指定账户”；删除分类后，原明细汇入对应收支类型的“未分类”。这样无需批量改写历史文件。
- “设置余额”会记录一个指定日期的余额校准值。该日期之前的余额流转照常保留；该日期之后的收支、转账继续作用于校准后的余额。余额校准不计入收支和预算。
- 预算只计算支出；一级分类预算包含其二级分类的支出。
- 首页和预算页进度颜色：已用低于 65% 为绿，65% 至低于 85% 为黄，85% 至低于 95% 为橙，达到或超过 95% 为红；未设置预算显示灰色。
- 活期利息每天按 `max(当日账户余额, 0) × 当日年化利率 ÷ 365` 累加，月末四舍五入到分，作为“利息”收入。修改利率从当天起生效。到账任务由后台每日检查，应用再次打开时也会补执行。
- 定期利息从开设日到到期日前一天按同样的每日正余额公式累加，在到期日一次入账；到期前不能从该账户支出或转出。
- v0.1.1 以百分数的万分之一为整数单位保存年化利率；旧版按百分数的百分之一保存的利率记录仍可读取。跨设备同步时，所有设备应先升级到 v0.1.1 再新增四位小数利率记录。
- 定时转账按首次日期推算后续日期。每个到期日产生一笔普通转账；同一任务、同一日期使用稳定标识，多设备重复执行不会形成两笔收入或支出。并发修改同一笔账目仍可能提示冲突。

应用内部用 Room 缓存不可变的“变更记录”。共享文件夹中每次新增、编辑、删除都会生成一个新的 JSON 文件，旧文件保留；这样两个设备同时新增记录不会覆盖同一文件。若离线时同时编辑同一对象，会在“设置”中显示冲突供选择。删除也作为变更记录同步，因此不要手工清理 `ledger-v1` 文件。

v0.2.0 为变更记录增加账本 ID；旧数据自动归入“我的账本”。若使用多设备同步，请先把所有设备升级到 v0.2.0，再创建新账本。

**隐私**：共享目录中的 JSON 是明文，能访问该目录或坚果云账号的人可以读取账目。此版没有端到端加密。

## 当前边界

- 无自动读取支付通知、银行接入、多币种、多人账本和备注全文搜索。
- 预算和活期利息按自然月。已结算的活期或定期利息不会因后来补录或修改历史账目而自动重算，需要人工核对并修改该笔收入。
- 安卓省电策略可延后后台任务；应用打开时会补齐到期转账和已结束月份的利息，不能保证整点或当天一定入账。
- 应用只负责本地文件的合并与冲突显示；坚果云文件传输由 FolderSync 负责。
